# 校园多源地图升级

用户已确认在现有纪念网站实施道路地图、多源卫星、照片联动的方案。保持静态部署和十种语言，继续使用按需加载的自托管 MapLibre。

地图区域提供道路/卫星按钮、当前模式下的来源选择、回到校园按钮。默认高德道路图；卫星可选 Esri World Imagery 当前影像和 Wayback 2023-06-29 发布快照（官方 catalog release 47963）。历史快照日期不是拍摄日期。天地图仅在 campusMap 元素配置 data-tianditu-key 后显示，提供道路和影像 WMTS。

切换保留地理视野、缩放和当前照片；机位数据保留 WGS84 语义，高德使用 GCJ-02 正反转换。机位中 estimated/approx 不是测量成果，本次不凭空修改位置。卫星不使用道路灰度滤镜。

按来源生成独立 source ID，避免过期瓦片事件污染新来源。来源加载状态支持超时、失败重试以及手动切回道路图。地图加载失败不影响照片漫游。所有动态 UI 提供十语文案、键盘操作、aria-pressed 和状态播报。

用户随后要求扩展多平台和 3D。现增加明确标注估计高度的「3D 视图」：Esri 或天地图影像 + OpenFreeMap 开放建筑挤出几何。它不宣称为实景测绘模型。天地图专用 Key 已申请并配置十语页面；高德官方 SDK、百度、腾讯和 Google 仍受各平台登录、实名或账号限制阻碍，未显示为可用来源。南昌实景三维成果留作文档中的后续数据渠道。使用来源版权说明，保持 Key 在公开前端可见这一事实。

验收：坐标往返、模式及来源切换、切换前后机位与相机一致、旧请求不影响新来源、失败重试、手机布局、十语页面、资源缓存指纹和现有全部测试。
